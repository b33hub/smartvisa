PP-OCRv4 text detection (det.onnx) and recognition (rec.onnx) models, converted to ONNX by the RapidOCR project
(https://github.com/RapidAI/RapidOCR), originally PaddleOCR (https://github.com/PaddlePaddle/PaddleOCR). Apache-2.0.
dict.txt = the recognition model's character table (index 0 = CTC blank, last index = space are added in code).
